Python tutorial and usage guide

Single-cell potency, trajectory, and regulatory-activity analysis

DiffPy estimates differentiation potency, quantifies signaling entropy, constructs potency-guided diffusion trajectories, and infers tissue-specific transcription-factor regulatory activity in epithelial cells from single-cell RNA-sequencing data. SCENT and its fast proxy CCAT quantify cell differentiation potency without requiring prior biological knowledge, whereas SCIRA infers regulatory activity from TF–regulon networks and target-gene expression patterns.

Set up DiffPyInstall the package and configure example datasets. Estimate cell potencyStart with signaling entropy, then explore CCAT, states, and trajectories. Estimate TF activityFollow the SCIRA regulatory-activity example after setup.

1. Overview

The package analyzes normalized single-cell RNA-sequencing expression matrices with genes in rows and cells in columns. Dense NumPy arrays, pandas DataFrames, and SciPy sparse matrices are supported.

Choose an analysis path below. Signaling entropy and CCAT estimate cell potency; SCIRA estimates transcription-factor activity.

2. Installation

Python examples below include their captured text output and embedded figures. Shell commands are setup instructions; installation and extraction logs depend on your environment.

Python 3.10 or newer is required. Install from the package source directory or a built distribution:

python -m pip install .

Install the optional tools needed to regenerate the documentation figures with:

python -m pip install ".[docs]"

Chu, liver, and stomach are distributed separately in DiffPy_test_data.zip. Extract the archive and configure its parent directory before running the cohort examples:

mkdir -p diffpy-data
unzip DiffPy_test_data.zip -d diffpy-data
export DIFFPY_DATA_DIR="$PWD/diffpy-data"

The environment variable may contain multiple directories separated by the platform path separator. The PPI networks and all nine tissue regulons remain bundled inside DiffPy. As an alternative to the environment variable, pass data_dir="/path/to/diffpy-data" to load_dataset().

The four bundled PPI networks use the canonical names ppi_PC_2012, ppi_PC_2016, ppi_PC_2024, and ppi_string_2020. Pass a canonical name to load_ppi(). The year shortcuts "2012", "2016", "2024", and "2020" are also supported.

load_dataset() returns an ordinary dictionary. Access expression matrices and annotations by key, for example chu["expression"] and chu["phenotype"]. Annotation vectors correspond to expression columns by position. Their pandas Series indices are not guaranteed to contain expression cell identifiers, so align them by order rather than joining them by index.

3.1 Expression preprocessing

The external test-data expression cohorts have different preprocessing histories. Do not apply another log transformation to the liver or stomach matrices.

Network integration and signaling entropy require nonnegative, library-size-normalized, unlogged expression. DoIntegPPI() always applies log2(x + 1.1); sparse input becomes dense because log2(1.1) is nonzero. An input maximum below 100 triggers a RuntimeWarning that the matrix may already be logged. CCAT and regulatory-activity estimation instead apply the sparse-safe transformation log2(x + 1) only when the input maximum exceeds 100, and emit a RuntimeWarning when they apply it.
DatasetLibrary-size normalizedLog-transformedTransformation

LiverYesYeslog2(x + 1.1)
StomachYes, scale factor 10,000Yeslog2(x + 1)

The integration step validates that expression is nonnegative, applies log2(x + 1.1), matches gene identifiers, checks overlap, and retains the largest connected network component. Supply library-size-normalized expression before log transformation. For each cell, signaling entropy builds expression-weighted transitions, calculates local Shannon entropy, and averages it using the stationary distribution.

Returned result

  • signaling_entropy: one normalized entropy score per cell.
  • stationary_distribution: gene-by-cell stationary probabilities.
  • local_entropy: gene-by-cell local transition entropy.
  • normalized_local_entropy: optional locally normalized entropy.
  • maximum_entropy: network normalization constant.

After estimating potency, InferPotencyStates() can determine whether cells separate into distinct potency states, which fits a mixture of Gaussians to logit-transformed SR values, or Z-transformed CCAT values. Next, we want to see how we can use CCAT to inform the choice of a root state for inferring lineage trajectories. While we could simply pick the cell with the highest CCAT value as the root cell, we aim to make this choice more robust. This is achieved by the function InferDMAPandRoot. Briefly, the function selects genes from normalized, log-transformed expression and constructs a diffusion map and a symmetric diffusion operator across all cells. Subsequently, it applies weighted Walktrap clustering to the graph restricted to the highest-potency cells. The proportion of cells selected is determined by the top_fraction argument. Walktrap identifies communities within this graph, and the largest community is taken to represent the root state. The root cell is then identified as the cell within the root state with the smallest mean absolute distance from the cluster's median coordinates across the retained diffusion axes. We now run the function:

trajectory = InferDMAPandRoot(
    potency,
    liver["expression"],
    k_neighbors=30,
    top_fraction=0.05,
)
dpt = compute_diffusion_pseudotime(
    trajectory,
    paths_to=(1, 2, 3),
)

print("Root cell:", trajectory.root_cell)
print(trajectory.diffusion_coordinates.iloc[:, :2].head())
print(dpt.pseudotime.head())

The required tissue argument selects one of the packaged regulons for breast, colon, esophagus, kidney, liver, lung, pancreas, skin, or stomach; custom regulon input is not supported. Activity is the t-statistic of the regulon-predictor slope in a linear regression, not the expression level of the transcription factor itself. Because transcription factors are rows and cells are columns, activity.mean(axis=0) calculates average TF activity for each cell.

InferDMAPandRoot(potency: 'Iterable[float] | pd.Series', expression: 'Any', *, expression_row_names: 'Iterable[Any] | None' = None, expression_col_names: 'Iterable[Any] | None' = None, mean_threshold: 'float' = 1.0, sd_threshold: 'float' = 0.25, k_neighbors: 'int' = 30, top_fraction: 'float' = 0.05, n_components: 'int' = 10) -> 'TrajectoryResult'

    Parameters

        Series is accepted, but cell order—not the Series index—is used for
        alignment.
    expression

    n_components

    Notes
    -----
    Walk-trap clustering is applied only to the highest-potency candidate
    subgraph. The largest community defines the candidate root state, and the

10. Reproducibility

Recalculate every tutorial figure

The figures above are generated by tools/generate_tutorial_plots.py. The script calls the public package API for every biological calculation, saves the plots under docs/images/, and records the displayed numerical summaries in docs/generated_results.json. Matplotlib is used only for rendering. The generator also runs tools/render_tutorial_outputs.py to execute the displayed Python examples and refresh their text and plot outputs.

python -m pip install -e ".[docs]"
PYTHONPATH=src python tools/generate_tutorial_plots.py --n-jobs 4

The state-model seed is fixed at random_state=0, and plotting jitter uses seed 260721. Diffusion axes can still reverse sign without changing the result's geometry.
