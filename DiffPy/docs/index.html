Python tutorial and usage guide

Single-cell potency, trajectory, and regulatory-activity analysis

DiffPy integrates signaling entropy, diffusion geometry, and TF regulatory activity inference for single-cell RNA-sequencing analysis. SCENT and its fast proxy CCAT quantify cell differentiation potency without requiring prior biological knowledge, whereas SCIRA infers TF regulatory activities from TF–regulon networks and target gene expression patterns.

1. Overview

The package analyzes normalized single-cell RNA-sequencing expression matrices with genes in rows and cells in columns. Dense NumPy arrays, pandas DataFrames, and SciPy sparse matrices are supported.

Following are the optional analysis paths.

2. Installation

Python 3.10 or newer is required. Install from the package directory:

python -m pip install /path/to/SCENT-SCIRA-Python

Alternatively, install the prebuilt wheel:

python -m pip install diffpy-2.0.0-py3-none-any.whl

Chu, liver, and stomach are distributed separately in DiffPy_test_data.zip. Extract the archive and configure its parent directory before running the cohort examples:

mkdir -p diffpy-data
unzip DiffPy_test_data.zip -d diffpy-data
export DIFFPY_DATA_DIR="$PWD/diffpy-data"

The PPI networks and all nine tissue regulons remain bundled inside DiffPy. As an alternative to the environment variable, pass data_dir="/path/to/diffpy-data" to load_dataset().

load_dataset() returns an ordinary dictionary. Access expression matrices and annotations by key, for example chu["expression"] and chu["phenotype"]. Annotation vectors correspond to expression columns by position. Their pandas Series indices are not guaranteed to contain expression cell identifiers, so align them by order rather than joining them by index.

3.1 Expression preprocessing

The external test-data expression cohorts have different preprocessing histories. Do not apply another log transformation to the liver or stomach matrices.

Network integration and signaling entropy requires nonnegative, library-size-normalized, unlogged expression and always applies log2(x + 1.1). Sparse input becomes dense because log2(1.1) is nonzero. CCAT and regulatory-activity estimation use a separate sparse-safe log2(x + 1). A maximum below 100 emits a RuntimeWarning that the matrix may already be logged.

ChuYesNoNone
LiverYesYeslog2(x + 1.1)
StomachYes, scale factor 10,000Yeslog2(x + 1)

4. Network integration and signaling entropy

integrate_expression_network(expression, network, *, min_overlap=5000) compute_signaling_entropy(integrated, *, include_normalized_local=False, n_jobs=1) 
from diffpy import (
    compute_signaling_entropy,
    integrate_expression_network,
    load_dataset,
    load_ppi,
)

chu = load_dataset("chu")
integrated = integrate_expression_network(
    chu["expression"],
    load_ppi("2012"),
)
entropy = compute_signaling_entropy(integrated, n_jobs=4)

print(entropy.signaling_entropy.head())
print(entropy.maximum_entropy)

The integration step validates that expression is nonnegative, applies log2(x + 1.1), matches gene identifiers, checks overlap, and retains the largest connected network component. Supply library-size-normalized expression before log transformation. For each cell, signaling entropy builds expression-weighted transitions, calculates local Shannon entropy, and averages it using the stationary distribution.

Returned result

  • signaling_entropy: one normalized entropy score per cell.
  • stationary_distribution: gene-by-cell stationary probabilities.
  • local_entropy: gene-by-cell local transition entropy.
  • normalized_local_entropy: optional locally normalized entropy.
  • maximum_entropy: network normalization constant.

5. Fast potency estimation with CCAT

compute_ccat(expression, network, *, min_overlap=5000) 
from diffpy import compute_ccat, load_dataset, load_ppi

chu = load_dataset("chu")
ccat = compute_ccat(chu["expression"], load_ppi("2012"))

print(ccat.describe())

CCAT calculates one Pearson correlation per cell between gene expression and PPI network degree. Higher values indicate stronger expression of highly connected genes.

6. Discrete potency states

infer_potency_states(potency, *, score_type="signaling_entropy", phenotype=None, variable_variance=True, max_states=5, random_state=0) 
from diffpy import infer_potency_states

states = infer_potency_states(
    ccat,
    score_type="ccat",
    phenotype=chu["phenotype"],
    random_state=0,
)

print(states.states.value_counts().sort_index())
print(states.distribution)
print(states.heterogeneity)

After estimating potency, infer_potency_states() can determine whether cells separate into distinct potency states. The function transforms the potency scores and fits Gaussian mixture models containing different numbers of states. It uses BIC to select a model that balances goodness of fit against unnecessary complexity. The inferred states are ordered from greatest to lowest potency, so state 1 always represents the greatest-potency group.

7. Diffusion trajectory and root-cell inference

infer_diffusion_root(potency, expression, *, mean_threshold=1.0, sd_threshold=0.25, k_neighbors=30, top_fraction=0.05, n_components=10) compute_diffusion_pseudotime(trajectory, *, root=None, paths_to=(1, 2, 3), window_width=0.1) 
from diffpy import (
    compute_ccat,
    compute_diffusion_pseudotime,
    infer_diffusion_root,
)
from diffpy import load_dataset, load_ppi

liver = load_dataset("liver")
potency = compute_ccat(liver["expression"], load_ppi("2012"))

trajectory = infer_diffusion_root(
    potency,
    liver["expression"],
    k_neighbors=30,
    top_fraction=0.05,
)
dpt = compute_diffusion_pseudotime(
    trajectory,
    paths_to=(1, 2, 3),
)

print("Root cell:", trajectory.root_cell)
print(trajectory.diffusion_coordinates.iloc[:, :2].head())
print(dpt.pseudotime.head())

The method filters variable genes, constructs an adaptive nearest-neighbor diffusion operator, and uses walk-trap clustering among the highest-potency cells. The selected root is closest to its root community's component-wise median across diffusion coordinates.

import matplotlib.pyplot as plt

dc = trajectory.diffusion_coordinates
plt.scatter(
    dc["DC1"], dc["DC2"],
    c=potency.to_numpy(), cmap="viridis", s=20,
)
plt.scatter(
    dc.loc[trajectory.root_cell, "DC1"],
    dc.loc[trajectory.root_cell, "DC2"],
    marker="*", s=180, c="red", label="root",
)
plt.xlabel("Diffusion component 1")
plt.ylabel("Diffusion component 2")
plt.legend()
plt.show()

8. Transcription-factor regulatory activity

estimate_regulatory_activity(expression, tissue, *, normalization="zscore", n_jobs=1) 
from diffpy import estimate_regulatory_activity, load_dataset

stomach = load_dataset("stomach")
activity = estimate_regulatory_activity(
    stomach["expression"],
    tissue="stomach",
    normalization="zscore",
    n_jobs=4,
)

print(activity.shape)       # transcription factors x cells
print(activity.iloc[:5, :5])

# Average across transcription factors to obtain one value per cell.
average_tf_activity = activity.mean(axis=0)
print(average_tf_activity.head())

The required tissue argument selects one of the packaged regulons for breast, colon, esophagus, kidney, liver, lung, pancreas, skin, or stomach. Activity is the t-statistic of the regulon-predictor slope in a linear regression.

10. Reproducibility

Recalculate every tutorial figure

The figures above are generated by tools/generate_tutorial_plots.py. The script calls the public package API for every biological calculation, saves the plots under docs/images/, and records the displayed numerical summaries in docs/generated_results.json. Matplotlib is used only for rendering.

python -m pip install -e ".[docs]"
PYTHONPATH=src python tools/generate_tutorial_plots.py --n-jobs 4

The state-model seed is fixed at random_state=0, and plotting jitter uses seed 260721. Diffusion axes can still reverse sign without changing the result's geometry.
